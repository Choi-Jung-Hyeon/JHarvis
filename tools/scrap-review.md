# 스크랩 선검토, 후적용

SNS나 뉴스에서 본 도구, 스킬, 팁을 그대로 설치하지 않고, 아래 순서로 판정한 뒤 쓸 것만 적용합니다.
판정은 [tool-radar.md](tool-radar.md)에 누적합니다. 같은 스크랩이 다시 오면 "기존 판정 유지" 한 줄로 끝냅니다.

## 판정 기준 (하나라도 걸리면 기각)

1. **비용**: 1원이라도 드나? API 키 종량제, 크레딧, 유료 플랜, 셀프 호스팅 서버 비용 포함.
2. **유지보수**: 서버, 도커, DB, 모델 파일을 따로 관리해야 하나? 설정이나 메모리를 별도로 관리해야 하나?
3. **토큰**: 매 대화에 붙는가(상시 연결 MCP, 매 턴 검토 플러그인)? 여러 에이전트를 병렬로 돌리나? 단계마다 문서를 만드나?
4. **라이선스**: 표기가 있나? MIT, Apache-2.0, BSD인가? 표기가 없으면 원문을 복사하지 않고 아이디어만.
5. **실체**: 원본 레포가 있나? "댓글 남기면 DM으로" 같은 미끼, 미러, 포크, 별 수 부풀리기는 아닌가?
6. **중복**: 이미 쓰는 것(내장 기능, 설치한 스킬, 규칙 문서)과 겹치나?
7. **안전**: 컴퓨터 전체 권한을 주는 상시 데몬, 운영 주소에 공격 도구를 돌리는 것, 약관 위반 수집은 아닌가?

## 판정 종류

| 판정 | 뜻 | 기록할 것 |
|---|---|---|
| 채택(적용) | 설치하거나 규칙에 넣었다 | 적용한 PR, 고정 SHA, 라이선스 |
| 사용 중 | 이미 쓰고 있다(새 판 확인) | 판 번호 |
| 규칙만 적용 | 도구는 안 깔고 내용 일부만 규칙에 반영 | 반영한 문서 위치 |
| 아이디어만 | 생각은 좋지만 설치하지 않음 | 어디에 어떻게 쓰나 |
| 필요할 때만 | 일회성으로 설치 없이(`pipx run`, `npx`) | 명령 |
| 개인 선택 | 레포 공용은 아니고 개인 세션에서만 | — |
| 기각 | 쓰지 않음 | 걸린 기준 번호와 한 줄 이유 |
| 기존 판정 유지 | 이미 판정함 | 원래 판정 날짜 |

## 채택할 때

- 원본 레포의 `SKILL.md`나 README를 직접 읽는다. 요약 글만 보고 설치하지 않는다.
- 커밋 SHA를 고정해 복사하고 라이선스 파일을 같은 폴더에 둔다. 원본을 고치지 않는다.
- 우리 규칙과 부딪히는 지시는 판정표(채택, 기각, 부분 채택과 이유)로 남긴다. 우선순위는 AGENTS.md > DESIGN.md > 스킬.
- 새 판이 나오면 바뀐 파일만 확인하고 SHA를 갱신한다.

## Claude Code에 맡기는 프롬프트

```
Goal
스크랩 목록을 JHarvis/tools/scrap-review.md 기준으로 판정하고 tool-radar.md에 추가한다.

Context
- 스크랩: <제목과 링크 목록>
- 이미 판정한 것은 tool-radar.md에 있다.

Constraints
- 하위 에이전트 없이, 끝나면 최종 보고 한 번. 아무것도 설치하지 않는다(판정만).
- 원본 레포와 공식 문서로 사실(라이선스, 별, 마지막 갱신, 비용)을 확인한다. 확인 못 하면 "미확인".

Done-when
- 스크랩마다 판정과 한 줄 이유가 tool-radar.md 표에 날짜와 함께 들어갔다(기존 판정이면 "기존 판정 유지").
- 채택 후보는 적용 방법(어느 파일에 무엇을)을 따로 제안한다.
- 최종 보고: 검토표 → 놓친 것 → 다음 프롬프트.
```
