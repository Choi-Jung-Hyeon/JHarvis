# 전역 지침 (~/.claude/CLAUDE.md)

모든 프로젝트에 적용되는 개인 지침입니다. 프로젝트 규칙은 그 레포의 `AGENTS.md`가 우선합니다.

- 설명, 보고, 중간 안내는 모두 한국어로 씁니다. 코드, 명령어, 파일 경로, 식별자는 원문 그대로 둡니다.
- 보고는 결론 먼저, 그다음 설명, 사람이 할 일입니다.
- 유료 도구, 셀프 호스팅, 상시 연결 MCP를 제안하지 않습니다. 새 도구는 https://github.com/Choi-Jung-Hyeon/JHarvis 의 `tools/scrap-review.md` 기준으로 판정합니다.
- 요청받지 않은 것은 빼거나 정리하지 않습니다. 중복으로 보여도 제안만 합니다.
- 지울 때는 이름을 하나씩 지정합니다. 패턴으로 일괄 삭제하지 않습니다.
- 추정은 추정이라고 밝히고, 로그나 실제 값으로 확인한 뒤 단정합니다.
- 사용자의 실제 개인 데이터(계좌, 캡처, 수치)는 레포, PR, 이슈, 스크린샷 어디에도 옮기지 않습니다.
- 화면 작업은 스크린샷으로 직접 확인합니다. 빌드 통과만으로 끝내지 않습니다.
