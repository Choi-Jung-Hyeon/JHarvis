# 03. 무료 운영

**기준: 단 1원이라도 들거나, 유지보수가 복잡하거나, 토큰을 많이 쓰면 쓰지 않는다.**

## 구조로 막기

- 클라우드(Vercel, Supabase 등)에 결제 수단을 등록하지 않는다. 플랜 업그레이드, 애드온, 유료 컴퓨트를 건드리지 않는다.
- 새 의존성은 무료 라이선스(MIT, Apache-2.0, BSD)만. 라이선스 표기가 없으면 복사하지 않는다.
- 유료 보안 기능(GitHub Advanced Security 등)을 켜지 않는다. 공개 레포의 무료 기능(Dependabot, CodeQL 기본)만.
- 외부 API는 하루 호출 상한을 코드에 둔다. 실행마다 남은 횟수를 로그로 남긴다.

## 예산표와 감시

- `docs/ops/free-tier-budget.md`: 자원 / 한도 / 현재 / 하루 증가 / 마감일 예상 / 대책([templates/free-tier-budget.md](../templates/free-tier-budget.md)).
- 주간 감시 워크플로: DB와 저장 공간 사용량, API 남은 횟수, 마지막 게시일, RLS가 꺼진 테이블, 가입 급증을 확인하고 기준을 넘으면 이슈를 연다. 예약 워크플로가 60일 비활성으로 꺼지지 않게 다시 켠다.
- 대량 적재 전에는 예산표의 남은 한도를 먼저 본다.

## 자주 쓴 절약 방법

| 문제 | 해법 |
|---|---|
| DB 용량 | 보존 정책(게시 배치 최근 N개, 원문 90일, 요약 로그만 영구) |
| 저장 공간 | 입력 파일은 남은 게시 배치만큼만 보존, 대용량 백업은 개인 클라우드 드라이브(sha256 대조 후에만 삭제) |
| 예약 실행 지연 | 정각과 30분을 피한 분(:07, :13, :37, :47) + 다음 날 예비 실행 |
| 함수 호출 | ISR 캐시(예: 1시간), 필요한 열만 조회 |
| 배포 저장 공간 | 미리보기와 실패 배포 정리, 문서만 바뀐 커밋은 빌드 건너뛰기 |
| LLM 비용 | 판단은 규칙 코드, LLM은 설명 문장에만. 로컬 모델 서버는 운영하지 않는다 |
