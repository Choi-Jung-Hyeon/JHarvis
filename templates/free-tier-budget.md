# 무료 한도 예산 (<운영 종료일>까지)

결제 수단은 등록하지 않습니다. 대량 적재 전에 이 표의 남은 한도를 먼저 봅니다.

| 자원 | 한도 | 현재(실측 날짜) | 하루 증가 | 종료일 예상 | 대책 |
|---|---|---|---|---|---|
| DB | <예: 500MB, 목표 300MB 이하> | | | | 보존 정책(게시 배치 최근 N개, 원문 90일) |
| 파일 저장 | <예: 1GB, 목표 600MB 이하> | | | | 남은 게시 배치만큼만 보존, 대용량 백업은 개인 드라이브 |
| 외부 API | <예: 총 2,000회> | | | | 하루 상한을 코드에 두고 실행마다 남은 횟수 로그 |
| CI 예약 실행 | 공개 레포 분 무제한, 60일 비활성 시 꺼짐 | | | | 정각과 30분을 피한 분, 주간 감시가 다시 켬 |
| 호스팅 | <대역폭, 함수 실행 한도> | | | | 캐시(ISR) |

| 항목 | 경고 기준 |
