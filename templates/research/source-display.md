# 출처와 기준 시점 표시 규칙

**규칙: 공통 기준 시점은 한 곳에 한 번, 항목 날짜는 다를 때만, 출처는 묶음 끝에 글로 한 번, 자세한 가공 설명은 접어 둔다.**

정보 서비스 몇 곳을 직접 열어 본 결과에서 정리했습니다. 프로젝트마다 아래 표를 채우고 빈칸의 위치를 정합니다.

| 정보 | 어디에, 몇 번 | 우리 화면 위치 |
|---|---|---|
| 공통 기준 시점 | 화면에서 한 곳에 한 번 | <상단 바 등> |
| 공통과 다른 날짜 | 그 항목 옆에, 다를 때만 | <오래된 데이터, 보고서 시점> |
| 늦은 데이터 | 경고와 함께("며칠 전 데이터") | |
| 출처 | 페이지나 묶음 끝에 글로 한 묶음 | <페이지 맨 아래 표> |
| 가공 과정, 인용 | 접기 안(이름은 '계산 근거') | |
| 색 범례 | 점 + 단어. 색 이름을 글로 쓰지 않는다 | |

## 버릴 것

| 버릴 것 | 이유 |
|---|---|
| 카드마다 "출처, 날짜" 접는 버튼 | 같은 날짜가 열 번 반복되면 정작 다른 날짜가 묻힌다 |
| 마우스를 올려야 보이는 설명 창 | 터치에서 열 방법이 없고, 포커스로 열리면 Tab 이동 중 화면을 가린다 |
| 열린 창 안의 또 다른 접는 버튼 | 두 번 눌러야 보이고 닫을 때 헷갈린다 |

## 조사 기록

조사할 때는 직접 열어 본 것과 문서로만 본 것을 나눠 적습니다. 확인하지 못한 곳은 기억으로 쓰지 않고 판정에서 뺍니다.
