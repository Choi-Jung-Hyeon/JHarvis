# 재현성 범위 — 기준 커밋 <SHA>

## 1. 정의
같은 입력 = <입력 스냅샷, 정책 파일, 엔진 상수, 시드>가 같다.

## 2. 무조건 보장 (해시가 같아야 한다)
- <설정 해시>, <계산 해시>, <리포트 본체> ...
- 이 절에는 LLM 판정이나 그 파생 상태를 넣지 않는다.

## 2.1 조건부 보장 (<조건>일 때만)
- <판정 결과 pass/fail>, <리포트 상태> ...

## 3. 제외 (달라도 재현 실패가 아니다)
- <판정 이유 문구>, <프롬프트 해시> ...

## 4. 대조 방법
- 명령: <replay 스크립트>
- 종료 코드: 0 일치 / <n> 보장 불일치 / <n> 조건부 불일치 / <n> 입력 오류
- 실측: N=<회>, 보장 대상 불일치 <건>

코드의 분류(GUARANTEED / CONDITIONAL / EXCLUDED)와 이 문서가 같아야 한다.
