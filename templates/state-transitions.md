# 상태 전이표와 출력 조건

| 현재 상태 | 이벤트 | 다음 상태 | 출력 가능 | 화면 문구 |
|---|---|---|---|---|
| draft | 분석 완료 | reviewed | 아니오 | |
| reviewed | 사람 승인 | locked | 예(조건 아래) | |
| reviewed | 판정 실패(상한) | blocked | 아니오 | |
| locked | 보는 안 변경 | locked | 아니오(잠금만) | |
| locked | 입력 변경 | draft | 아니오 | |

출력 가능 = <상태 === locked> AND <보는 안 === 확정 스냅샷>
상태 값과 전이는 모듈 하나(<경로>)에만 정의한다.
