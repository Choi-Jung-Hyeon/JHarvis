# 회의록 템플릿

30분, 길어도 1시간. 혼자나 1:1로 풀 수 있는 것은 안건에서 뺍니다.

```markdown
# <날짜> 회의

| 시간 | 안건 | 정할 것 |
|---|---|---|
| 0~5분 | 지난 결정 확인 | — |
| 5~20분 | 안건 1 | A / B / C 중 하나 |
| 20~30분 | 안건 2 | 담당과 마감 |

## 안건 1: <제목>
- 핵심: <한 줄>
- 논의: <의견 요지, 사람 평가 없이>
- 아이디어 후보: <나중에 볼 것>
- 결정: <A>. 의견이 없으면 <시각>에 A로 진행.

## Done / Todo / Discuss
| 구분 | 내용 | 담당 | 마감 |
|---|---|---|---|
| Done | | | |
| Todo | | | |
| Discuss | | | |

## 실시간 메모
- <회의 중 그대로 받아 적은 것>
```
