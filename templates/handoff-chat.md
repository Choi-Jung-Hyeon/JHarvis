# 새 채팅 인수인계 템플릿

채팅이 길어지면 채팅 Claude에게 "인수인계 문서를 이 형식으로 만들어 프로젝트 문서에 저장해 주세요"라고 요청합니다.
새 채팅 첫 메시지: "프로젝트 문서 `<경로>`를 읽고 그대로 이어가 주세요."

```markdown
# <프로젝트> 새 채팅 인수인계 (<날짜 시각> 기준)

## 내 역할과 응답 방식
- 역할: <기술 파트너, PM 보조 등>. 사용자는 <이름, 역할>.
- 응답: 결론 → 자세한 설명 → 교통정리(표) → 넥스트 액션(번호 목록). 과감하게 진행하고 되돌릴 수 없는 결정만 묻는다.
- Claude Code 프롬프트: Goal / Context / Constraints / Done-when, 하위 에이전트 없이 최종 보고 한 번. 결과는 /export로 받는다.
- 기록: 끝난 일은 <노션 페이지>에 체크와 취소선.
- 팀에 보내는 문구: <짧게, 반말/존댓말>.

## 반드시 지킬 것
- <개인정보, 비용, 팀원 표현, 금지어, 남의 이름으로 글 달지 않기 등>

## 다루지 않는 것
- 이 채팅은 <과제> 전용이다. <다른 과제>는 다루지 않는다.

## 프로젝트 핵심 사실
- 목표, 범위, 저장소와 주소, 스택, 팀과 담당, 확정 수치(출처와 함께)

## 현재 상태
- 끝난 것 / 진행 중(누가, 언제까지) / 막힌 것 / 알려진 문제

## 일정
| 언제 | 누가 | 무엇을 |
|---|---|---|

## 링크
- 노션 <페이지 이름과 ID>, 저장소, 배포 주소, 주요 이슈

## 새 채팅 첫 할 일
1. <무엇이 오면 무엇부터>
2. ...
```
