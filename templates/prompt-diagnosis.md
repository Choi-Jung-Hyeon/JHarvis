# 진단 전용 프롬프트

코드를 고치지 않는 정찰용입니다. 원인을 확인한 뒤 실행 프롬프트를 따로 씁니다.

```text
코드는 고치지 않는다. 진단과 제안까지만. 결과는 CLI로.

A. [<스캔 이름>] <무엇을> 파일:줄 단위로 나열. 각 지점이 <원칙>을 지키는지 표시.
B. [<스캔 이름>] ...
C. [데이터 흐름] <LLM 출력>이 <계산 함수>의 입력으로 들어가는 경로가 있는지 추적. 있으면 경고.
D. [우선순위] A~C 발견을 (1) 마감 전 필수 (2) 뒤로 미뤄도 됨 으로 나누고 작업량(소/중/대).

보고 규칙: 원인 후보는 "확인됨(근거 파일:줄)"과 "추정"으로 나눈다.
금지: 새 기능 제안, 아키텍처 변경 제안, 다른 프로젝트 얘기.
```
