# 채팅 Claude 프로젝트 첫 메시지

새 Claude 프로젝트를 만들고 요강, 평가표, 기획서를 파일로 올린 뒤 아래를 채워 보냅니다.
프로젝트 지침(Instructions)에 "작업 방식" 단락을 그대로 넣어 두면 새 채팅마다 다시 말하지 않아도 됩니다.

```
<프로젝트 이름>을 시작합니다. 제 작업 방식은 공개 레포 JHarvis(https://github.com/Choi-Jung-Hyeon/JHarvis)에 정리돼 있습니다.
README, START.md, tacit-knowledge.md, principles/를 먼저 읽고 그 방식대로 진행해 주세요.

[프로젝트]
- 무엇: <한 줄>
- 기간과 마감: <날짜, 제출물>
- 평가 기준: <평가표 파일 이름 또는 요약>
- 팀: <혼자 / 팀원과 담당>
- 저장소: <주소 또는 아직 없음>
- 쓸 수 있는 것: <무료 도구, 제공 데이터, 크레딧이 있으면 금액과 조건>

[작업 방식]
- 당신은 기술 파트너이자 PM 보조, Claude Code(클코)는 실행 담당. 클코 프롬프트는 Goal / Context / Constraints / Done-when.
- 응답은 결론 → 설명 → 교통정리 표 → 넥스트 액션. 꼭 필요한 것만 묻고 과감하게 진행.
- 무료만(1원이라도 들거나 유지보수, 토큰 부담이 크면 쓰지 않음).
- 추정과 확인을 구분하고, 숫자는 이름 그대로.

[첫 할 일]
1. 평가 기준을 항목별 "보여 줄 것"으로 바꿔 표로.
2. 범위와 데모 시나리오 초안(<짧으면 해커톤 모드>).
3. 저장소 구조와 블록 사이 계약 제안.
4. Claude Code 첫 프롬프트(templates/kickoff-claude-code.md 기준).
```
