# 실패 시 정지 규칙

| # | 규칙 | 숫자 상수 위치(유일) | 위반 시 상태 | 확인 테스트 |
|---|---|---|---|---|
| R1 | 판정이 재시도 상한까지 실패하면 사람 검토 대기에서 멈춘다 | <config 경로: 키> | blocked | <테스트 이름> |
| R2 | 인용은 문장 + 출처 메타가 맞을 때만 통과 | — | blocked | |
| R3 | 확정(locked)일 때만 최종 출력 | — | — | <속성 테스트> |

- 문서와 화면은 숫자를 직접 쓰지 않고 위 위치를 참조한다.
- 폴백 기본값을 두지 않는다(설정이 없으면 실패).
- 심각도: block(사람도 못 넘김) / review(사유를 남기고 사람이 넘길 수 있음)
