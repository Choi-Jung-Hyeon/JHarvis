# 시연 런북

## 사전 (D-1 밤)
- [ ] 마지막 커밋 시각 <HH:MM>, 이후 동결
- [ ] 환경변수 목록 확인(사람)
- [ ] 백엔드 워밍업 <몇 분 전>
- [ ] 시연 계정, 입력 대본 인쇄

## 시연 동선
| # | 시점 | 화면 | 입력 | 보여 줄 것 | 하이라이트 |
|---|---|---|---|---|---|
| 1 | 상담 전 | | | | |
| 2 | 상담 중 | | | | |
| n | 차단 | | | 실패 시 출력이 잠긴다 | ★ |
| n+1 | 복구 | | | 승인 → 확정 → 출력 | |

## 모의 감사 (지정된 건)
- 5분: <run_id> 증거 묶음 열기 → manifest 해시 → 판정 사유 → 승인 이력 → (차단 건이면) 멈춘 기록
- 3분: 같은 입력 재실행 → 대조 스크립트 → 종료 코드 0
